# Provenance

This repository was developed together by Xiaoxu and CC from a behavior specification derived from their separate private prototype.

The public code is intentionally rewritten with new module boundaries, names, API shapes, interface copy, styling, and tests. Private application source, conversation data, prompts, infrastructure details, and deployment configuration are not included.

Related open-source projects were reviewed only to understand the surrounding ecosystem and licensing landscape. Their source code was not used here. See `RELATED_WORK.md`.

The collaboration and respective contributions are described in `AUTHORS.md`.
